# 질의 임베딩 $\rightarrow$ 유사도 검색 $\rightarrow$ 프롬프트 조합 $\rightarrow$ LLM 질의 방식

[클라이언트 / 사용자 시스템]
         │  (1) 사용자 질문 요청 (HTTP REST)
         ▼
┌───────────────────────────────────────────────────────────┐
│              Java 메인 애플리케이션 (Spring Boot 등)        │
│                                                           │
│  1. 질문 접수                                              │
│  2. Ollama에 임베딩 요청 (bge-m3)                           │
│  3. 반환받은 벡터로 Vector DB에 유사도 검색 쿼리           │
│  4. 검색된 관련 문서 + 사용자 질문을 합쳐 프롬프트 구성       │
│  5. Ollama에 생성 요청 (qwen3-coder:30b)                  │
│  6. 최종 답변 클라이언트에 반환                              │
└───────┬───────────────────────────┬───────────────────────┘
        │ (2) 질의 임베딩           │ (3) 유사 문서 검색
        │     & (5) LLM 추론       │     (Vector Query)
        ▼                           ▼
┌───────────────────────────┐   ┌───────────────────────────┐
│     Ollama 서비스 런타임   │   │         Vector DB         │
│                           │   │                           │
│  - bge-m3 (임베딩 모델)    │   │  - 사전 적재된 사내 데이터 │
│  - qwen3-coder:30b (LLM)  │   │  - Milvus / pgvector 등   │
└───────────────────────────┘   └───────────────────────────┘
