### (A) 대기 분류: 7분류 vs 목업 8분류 — **결정: 8분류 (2026-09-25, 설계 문서 반영 완료)**
- 반영 내용: 소스는 ASH `wait_class`. 60초 샘플러의 기존 ASH 쿼리 1회 스캔에서 7분류(`ash_*`, Current Session용 유지)와 8분류(`ash_wc_*` 신규)를 같이 집계. 기동 시 1시간 backfill. ② 라벨 "Oracle 대기 클래스 기준". 색·④ 조치 문구는 목업 기준 복원. `dbClockOffsetMs`를 샘플러가 캐시해 `/api/metric_history`로 전달.

(결정 전 검토 내용)
- 오케스트레이터 지적: 7분류는 Current Session의 **Active Session 리스트**에 맞춘 것(체크리스트 1-10). 대시보드는 세션 리스트를 걷어내므로 그 이유가 그대로 적용되지 않음.
  또 목업 ③ Lock 카드는 TX/TM을 선 색 + 상단 건수로 이미 구분함 → "8분류면 Lock 구분 불가"라는 검토 지적은 과장이었음(②차트 한 곳만 합쳐짐). 문서 2.3 근거 문구는 수정 완료.
- 7분류로 고친 실제 이유는 (1) 이미 쌓인 `ash_*` 데이터 재사용(편의), (2) 탭 간 숫자 일치(약한 이유) 뿐.
- **Claude 권장안**: 목업대로 8분류 + 소스는 ASH `wait_class`
  - ②: 기존 60초 샘플러 쿼리에 8분류 집계 추가 → `ash_wc_*` 8개 metric 저장 (원본 DB 조회 증가 없음)
  - ⑤⑥⑦·드로어: `ash_base` 분류만 wait_class 기준으로 교체
  - 배포 직후 빈 이력: 체크리스트 1-10의 "기동 시 ASH 1시간 backfill" 같이 적용
  - 차트 라벨에 "Oracle 대기 클래스 기준" 표기로 Current Session(7분류)과 구분
- 채택 시 문서 수정 범위: 2.3 색·분류, 4.1/4.3 샘플러 추가, ④ 조치 문구(목업 기준으로 복원), 10장 수용 기준

### (B) 검토 지적 중 아직 문서에 반영 안 한 것
- **KILL 안전성 (Critical)**
  - 기본값 `blockingOnly=false` + 60초 미만 Holder까지 기본 전체 선택 → 기존(막고 있는 Holder만)보다 위험. 기본 blocking-only 권장
  - 확인 패널 열린 채 DB 전환 시 다른 DB로 SID 전송 위험 (`app.js` KILL이 클릭 시점 `window.currentDbId` 사용)
  - 조건 해소 시 패널 자동 닫힘 → 2초 폴링에서 깜빡임. "조건 해소됨" 표시 + 비활성으로 변경 권장
  - 기존 `/api/kill_session`은 `canAccessDb`·서버측 `type='USER'`·감사 기록 없음 → 신규 KILL API 필요
- **저장소**: DDL이 Oracle 문법, 실제는 SQLite(메인)/H2+Java8(AIX) — 문서에 변환 원칙만 추가함
- **③ Lock 2초 조회 부하**: v$lock 49초 실측 전례. Holder 수 DISTINCT 필요(오탐), TM 대기 1건 이상일 때만 Holder 조회, 기존 `failureProbInFlight` 중복제거 패턴 재사용
- **기존 뷰·체크리스트 충돌**: 레거시/v2 스위치와의 관계 미정의(현재 코드 스위치는 legacy/v2 2개), 세션 목록 제거가 체크리스트 1-7(Duration 정렬)·1-8(세션 목록 탭)·9-1(프레임 통합)과 충돌, 테이블스페이스 기준 v2 97% vs 신규 85/90%
- **⑧ 점검 쿼리**: TEMP는 `dba_temp_free_space` 사용, FRA는 `NULLIF(space_limit,0)`(미설정 DB ORA-01476), `dba_segments`/`dba_tab_statistics`는 1일 주기로
- **SQL 통계 델타**: PK에 plan_hash_value 없음, 재기동 첫 수집·음수 대체 규칙이 급등값 생성
- **자동 구간 선택 UX**: 장애 진행 중 열면 과거 피크가 선택될 수 있음, 재계산 시점 정의 필요
- **폐쇄망/프론트**: 목업 Google Fonts, `color-mix()`(Chrome 111+)·`dvh`, `.app-container zoom:90%`에서 드로어 위치(body 직하 배치), http에서 클립보드 불가, 라이트 테마 미정의
- **상태 누락**: 로딩 스켈레톤, 데이터 공백(끊어 그리기), stale 배지, 503 "판단 보류", 403, 비Oracle DB, 수집 실패 표시
- **문서/목업 불일치(Low)**: 7/8프레임, 목업 ASH/AWR 문구, Top SQL 5/6개, KILL 구문 복사 권한, 구간 변경 시 선택 유지 여부, TM 경고선 기준
