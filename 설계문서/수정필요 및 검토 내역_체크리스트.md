# DBAgent-Java & DBAgent-Java-AIX 수정 필요 및 검토 내역

** 1 번째 **
  1. [ ] Current Session 매뉴의 실시간 세션 모니터링 좌측 그래프(Active Session Wait Class) CPU 개수 구하는 쿼리 변경 필요
    - 현재 v$parameter 의 cpu_count 를 가지고 오는데 이 값은 AAS 와 비교하여 성능 분석 하기에는 적합하지 않음
    - 현재 DB가 사용하고 있는 실재 값이 필요
    > 변경 Query (IBM 박스가 전체가 아닌 실제 IBM DB서버 파트에서 사둉되는 CPU 개수)
    >> SELECT stat_name, value 
       FROM v$osstat 
       WHERE stat_name = 'NUM_CPU_CORES';
  2. [ ] Current Session 매뉴의 실시간 세션 모니터링 그래프 로딩 성능 문제
    - 로그인 후 Current Session 매뉴에 접근하면 그래프 로딩 속도가 매우 느림, 처음에는 그냥 까만 화면만 있다 조금 지나서  좌측 그래프(Active Session Wait Class) 로딩 후 더 시간이 지난후 우측 그래프(Top SQL Activity Timeline) 로딩
  3. [ ] 우측 그래프(Top SQL Activity Timeline) 드래그 기능 개선 필요. 
    - 현재 색 별로 정교하게 드래그가 되는게 아니라 세로로 길개 구간 단위 드래그만 되고 있음, 일부러 의도한 건지 궁금
    - 좌측 그래프(Active Session Wait Class) 그래프도 드래그 하여 세션정보 볼수 있는 기능이 구현 필요
  4. [ ] Current Session 매뉴 하단 Active Session 조회 리스트의 갯수가 7개 이상이 되면 우측 스코롤바 생성 되게 구현 하여 더 이상 조회 화면이 늘어나는거 방지 필요
  5. [ ] 다른 DB 또는 RDB, FO 접근후 다시 돌아 오면 그래프 차트 정보가 잘 갱신되지 않음(갱신 되는데 매우 오래걸리고, 가끔 그래프 부분이 검은 화면으로 먹통이 됨)
  6. [ ] Current Session 매뉴 우측 그래프(Top SQL Activity Timeline) 도 좌측 그래프(Active Session Wait Class) 처럼 색별 개열 클릭시 그래프 내용 필터링 되도록 구현
  7. [ ] 첫번째 대시보드 와 Current Session 매뉴 의 Active Session 조회 내용 중 Duration Time(sec) 필드 클릭시 오름 차순 내림 차순 정열 되도록 수정
  8. [ ] 첫번째 대시보드의 Active 세션 목록, Top 이벤트 목록 텝을 ->  Active Session, Active Transaction, Parallell     Session, Remote, 2pc Pending Transaction, Top Events 텝 매뉴로 구성해줘
    - Current Session 매뉴의 Active Session, Active Transaction, Parallell Session, 2pc Pending Transaction ->    Active Session, Active Transaction, Parallell Session, Remote, 2pc Pending Transaction 변경해줘 즉 Remote 텝 매뉴 신규 추가해줘 
  9. [ ] Current Session 매뉴 리프레쉬 주기 3초 디폴트로 만들어줘 현재 5초(만약 프로퍼티에서 설정할수 있으면 설정 프로퍼티 알려줘)
