# DBAgent-Java & DBAgent-Java-AIX 수정 필요 및 검토 내역

  1. [x] Current Session 매뉴의 실시간 세션 모니터링 좌측 그래프(Active Session Wait Class) CPU 개수 구하는 쿼리 변경 필요
    - (2026-09-25 완료) 코어 기준선(Current Session 차트, 60초 샘플러 ash_cpu_cores)을 NUM_CPU_CORES로 변경(없으면 NUM_CPUS). CPU 사용률(%) 분모는 NUM_CPUS 유지 - SMT 서버에서 CPU%가 100%를 넘지 않게(오케스트레이터 결정). 로컬 XE 32 → 16 확인
    - 현재 v$parameter 의 cpu_count 를 가지고 오는데 이 값은 AAS 와 비교하여 성능 분석 하기에는 적합하지 않음
    - 현재 DB가 사용하고 있는 실재 값이 필요
    > 변경 Query (IBM 박스가 전체가 아닌 실제 IBM DB서버 파트에서 사둉되는 CPU 개수)
    >> SELECT stat_name, value 
       FROM v$osstat 
       WHERE stat_name = 'NUM_CPU_CORES';
