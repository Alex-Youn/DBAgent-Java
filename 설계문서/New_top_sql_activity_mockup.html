Active Session + Top SQL Activity — 목업

두 그래프를 나란히 배치 · Top SQL 타임라인은 드래그로 구간을 선택해 세션 상세를 확인

왼쪽은 기존 Active Session(대기 유형별) 그래프, 오른쪽이 이번에 추가한 Top SQL Activity Timeline입니다. 같은 시간축을 공유해서 "언제 세션이 몰렸는지"와 "그 시점에 어떤 SQL이 주된 원인이었는지"를 함께 볼 수 있습니다. 색상은 두 그래프가 동일한 이벤트 팔레트를 공유합니다 — 오른쪽 SQL이 올리브색이면 그 SQL은 주로 Latch 대기, 보라색이면 TX Lock 대기가 특징이라는 뜻이라 왼쪽 그래프와 바로 대응해서 볼 수 있습니다(범례에 카테고리를 함께 표기). 실시간 갱신 시에도 같은 색=같은 이벤트 규칙은 고정되어 있어 매번 다시 파악할 필요가 없습니다. 오른쪽 그래프에서 마우스로 구간을 드래그하면 그 구간에 활동한 세션 상세 목록이 아래에 나타납니다.
