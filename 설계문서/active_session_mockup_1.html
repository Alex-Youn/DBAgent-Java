Active Session 모니터링 – 목업

Wait Class 별 Active Session 추이 · 샘플 데이터

지정하신 색상(CPU/Latch/User I/O/TX Lock/Sys I/O/TM Lock/Other)으로 구성한 목업입니다. 기본은 대기 유형별 누적 영역 차트이며, 상단 세그먼트에서 누적 막대 차트로 전환할 수 있습니다. 표시 순서(범례·스택 순서)는 색약(CVD) 시뮬레이션 검증을 거쳐, 색상이 서로 가까운 Latch(올리브)가 Sys I/O·TM Lock·Other(회색)와 바로 인접하지 않도록 배치했습니다 — 순서를 바꾸시면 이 안전성이 깨질 수 있어, 필요하시면 다시 검증해 드릴게요. 데이터는 예시용으로 생성된 값이며, I/O 병목 구간과 락 경합(Lock Contention) 구간을 구분해서 보여줍니다.

색상 팔레트는 색각이상(CVD) 대응 검증을 거친 기본 팔레트를 사용했습니다. 범례는 항상 표시되며, "고대비 텍스처" 체크박스로 색상 없이도 구분 가능한 패턴 채우기로 전환할 수 있습니다.
