# 팝업 통일 스펙 (G2)

- 작성: 2026-09-26
- 근거: 체크리스트 4-2(세로형 → 가로형), 전체 작업순서 G2
- 기준 사례: G1 세션 상세정보 팝업(`session-detail.html`)
- 적용 범위: 모든 팝업 창(`window.open`) - 환경설정 팝업도 포함(2026-09-26 변경)
- 공용 파일: `static/popup.css`, `app.js`의 `dbagentPopupFeatures()`

## 1. 창

| 항목 | 값 |
|---|---|
| 모양 | 가로형 |
| 기본 크기 | 1100 × 680 (`dbagentPopupFeatures()`) |
| 넓은 팝업 | 내용이 많을 때만 폭을 넓힌다. 예: `dbagentPopupFeatures(1200, 800)` |
| 창 이름 | `dbagent_<종류>_<키>`. 같은 대상을 다시 누르면 새 창을 만들지 않고 기존 창을 다시 쓴다 |

## 2. 배율과 글씨

| 항목 | 값 |
|---|---|
| 배율 | 본문(`.app-container`)과 같은 `zoom: 90%` (`.pp-root`) |
| 높이 보정 | `height: calc(100vh / 0.9)`. zoom은 뷰포트 단위를 줄이지 않으므로 본문과 같은 방식으로 보정한다 |
| 기준 글씨 | 14px (화면에서는 약 12.6px) |
| 표 글씨 | 13.5px |
| 코드(SQL·Plan) | 13px / 12.5px |

## 3. 구성 (위에서 아래로)

1. **제목 줄** `.pp-head`: 제목(`h3`), 필요할 때 안내 문구(`.pp-note`), 오른쪽 끝 버튼 묶음(`.pp-actions` > `.pp-btn`)
2. **요약 표** `.pp-kv`: 한 행에 라벨·값 4쌍(8칸). 값이 넘치면 말줄임하고 전체 값은 `title`로 보여 준다
3. **본문**: 둘 중 하나
   - 탭 `.pp-tabs` > `.pp-tab-headers` > `.pp-tab-btn` / `.pp-tab-body`
   - 목록 `.pp-table-wrap` > `.pp-table` (머리글 고정, 표 영역 안에서만 스크롤)

본문은 남은 높이를 채우고, 창 전체가 아니라 본문 영역 안에서만 스크롤한다.

## 4. 공통 규칙

- 화면에 넣는 DB 값은 모두 HTML 이스케이프한다(SQL 텍스트·Plan·바인드 값 포함).
- 값이 없으면 `-`로 표시한다.
- 테마는 메인 화면에서 저장한 값(`dbagent_theme`)을 따른다.
- 인증 토큰은 `sessionStorage`를 쓰므로, 팝업은 메인 화면에서 연다.

## 5. 적용 대상

| 팝업 | 파일 | 크기 | 단계 |
|---|---|---|---|
| 세션 상세정보 | `session-detail.html` | 1100×680 | G1·G2 (기준 사례) |
| Event 세션 목록 | `perf-event-sessions.html` | 1100×680 | G3 (첫 신규 적용) |
| 선택 세션 목록 | `session-list.html` | 1100×680 | G4 |
| 테이블 정보 | `table-info.html` | 1100×680 | G4 |
| 테이블스페이스 데이터파일 | `tablespace-datafiles.html` | 1100×680 | G4 |
| ERD | `app.js` `dbagent_erd_popup` | 1200×800 (넓은 팝업) | G4 |
| 계정 관리 | `account-mgmt.html` | 1100×680 | G4 (환경설정) |
| DB 관리 | `db-mgmt.html` | 1100×680 | G4 (환경설정) |
| 메뉴 표시 설정 | `menu-visibility.html` | 1100×680 | G4 (환경설정) |

**환경설정 팝업 포함 (2026-09-26 오케스트레이터 결정)**: 처음에는 설정(톱니) 메뉴의 팝업 3개를 제외했지만, 기본 크기와 틀 모양을 다른 팝업과 같게 맞추기로 바꿨다.
- 창 크기: `dbagentAdminPopupFeatures()`가 항목 수로 계산하던 크기 대신 1100×680 고정. 콘텐츠에 맞춰 창을 늘리던 `dbagentAutoSizePopup()`은 아무것도 하지 않는다(넘치는 내용은 `.pp-root` 안에서 스크롤).
- 틀: 로그인 화면용 `.login-card` 카드 장식을 팝업 안에서는 걷고, 각 화면의 첫 제목을 `.pp-head`와 같은 모양으로 맞춘다(`popup.css` 환경설정 블록).
- 예전 팝업의 제목(`h2`/`h3`)은 `.pp-title` 클래스로 같은 모양을 입힌다.

화면 안 모달(비밀번호 변경 등)은 창이 아니라서 이 스펙의 대상이 아니다.
