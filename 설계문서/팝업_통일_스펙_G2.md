# 팝업 통일 스펙 (G2)

- 작성: 2026-09-26
- 근거: 체크리스트 4-2(세로형 → 가로형), 전체 작업순서 G2
- 기준 사례: G1 세션 상세정보 팝업(`session-detail.html`)
- 적용 범위: 환경설정 팝업을 뺀 모든 팝업 창(`window.open`)
- 공용 파일: `static/popup.css`, `app.js`의 `dbagentPopupFeatures()`

## 1. 창

| 항목 | 값 |
|---|---|
| 모양 | 가로형 |
| 기본 크기 | 1100 × 680 (`dbagentPopupFeatures()`) |
| 넓은 팝업 | 내용이 많을 때만 폭을 넓힌다. 예: `dbagentPopupFeatures(1200, 800)` |
| 창 이름 | `dbagent_<종류>_<키>`. 같은 대상을 다시 누르면 새 창을 만들지 않고 기존 창을 다시 쓴다 |

## 2. 배율과 글씨

| 항목 | 값 |
|---|---|
| 배율 | 본문(`.app-container`)과 같은 `zoom: 90%` (`.pp-root`) |
| 높이 보정 | `height: calc(100vh / 0.9)`. zoom은 뷰포트 단위를 줄이지 않으므로 본문과 같은 방식으로 보정한다 |
| 기준 글씨 | 14px (화면에서는 약 12.6px) |
| 표 글씨 | 13.5px |
| 코드(SQL·Plan) | 13px / 12.5px |

## 3. 구성 (위에서 아래로)

1. **제목 줄** `.pp-head`: 제목(`h3`), 필요할 때 안내 문구(`.pp-note`), 오른쪽 끝 버튼 묶음(`.pp-actions` > `.pp-btn`)
2. **요약 표** `.pp-kv`: 한 행에 라벨·값 4쌍(8칸). 값이 넘치면 말줄임하고 전체 값은 `title`로 보여 준다
3. **본문**: 둘 중 하나
   - 탭 `.pp-tabs` > `.pp-tab-headers` > `.pp-tab-btn` / `.pp-tab-body`
   - 목록 `.pp-table-wrap` > `.pp-table` (머리글 고정, 표 영역 안에서만 스크롤)

본문은 남은 높이를 채우고, 창 전체가 아니라 본문 영역 안에서만 스크롤한다.

## 4. 공통 규칙

- 화면에 넣는 DB 값은 모두 HTML 이스케이프한다(SQL 텍스트·Plan·바인드 값 포함).
- 값이 없으면 `-`로 표시한다.
- 테마는 메인 화면에서 저장한 값(`dbagent_theme`)을 따른다.
- 인증 토큰은 `sessionStorage`를 쓰므로, 팝업은 메인 화면에서 연다.

## 5. 적용 대상

| 팝업 | 파일 | 현재 크기 | 단계 |
|---|---|---|---|
| 세션 상세정보 | `session-detail.html` | 1100×680 | G1·G2 적용 완료(기준 사례) |
| 세션 목록(event 클릭) | 신규 | - | G3 (첫 신규 적용) |
| 선택 세션 목록 | `session-list.html` | 1000×600 | G4 |
| 테이블 정보 | `table-info.html` | 900×720 | G4 |
| 테이블스페이스 데이터파일 | `tablespace-datafiles.html` | 1000×600 | G4 |
| ERD | `app.js` `dbagent_erd_popup` | 1200×800 | G4 (넓은 팝업 유지) |

**제외 (환경설정 팝업)**: 설정(톱니) 메뉴의 계정 관리(`account-mgmt.html`), DB 관리(`db-mgmt.html`), 메뉴 표시 설정(`menu-visibility.html`). 이 팝업들은 목록 길이에 맞춰 창 크기를 계산하는 기존 방식(`dbagentAdminPopupFeatures`)을 그대로 쓴다.

화면 안 모달(비밀번호 변경 등)은 창이 아니라서 이 스펙의 대상이 아니다.
